# Pawchive Ripper v0.9.1

Archive Pawchive/Kemono Patreon and Fanbox posts or Discord channels on your device. This release includes the media scanner fixes, exact duplicate handling and matching Pawchive UI developed since v0.7.0.

## Changes

- Recognize Pawchive's partitioned original paths for images, MP4s and source archives; generate the correct thumbnail paths and read their sync identities.
- Offer exact duplicate attachment reuse and searchable archive/version selection. With extraction enabled, byte-identical unpacked files share one retained copy; translations and different edits remain separate.
- Retain shared-file references through ZIP export and folder sync, recover missing outputs, and preserve single-post/subset scope.
- Use Pawchive naming/theme and improve discovery lookup, queue scheduling, ZIP preparation and directory verification.
- Provide MIT licensing, complete bundled dependency notices, synthetic image fixtures, reproducible ZIPs, SHA-256 checksums and CI/release tooling.

## Install or update

Download **pawchive-ripper-0.9.1.zip** and extract it. Enable Developer mode at your browser's extensions page, choose **Load unpacked**, and select the extracted folder containing `manifest.json`. GitHub's automatic source archives require a build and are not the installable extension.

For an existing unpacked installation, replace files inside its existing folder, reload the extension, and refresh the site tab. Keep that folder path to preserve the extension identity and local jobs. Refresh an old scan once before downloading if media was missed previously.

For recurring bundles, enable **Avoid exact duplicates** and **Extract downloaded archives**. Different ZIPs still need their first download for content comparison; exclude unwanted bundles in **Archives & versions** to avoid that transfer. Existing earlier copies stay on disk. `duplicates.json` records retained locations.

The release ZIP includes licenses and dependency notices. `SHA256SUMS.txt` contains its checksum. See the README for folder permissions, sync, extraction limits and privacy details.
